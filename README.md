# Organización automática de archivos

## Descripción
Este proyecto es un programa en Python que sirve para organizar archivos automáticamente dentro de una carpeta. La idea es que no tengas que hacerlo manualmente.

## ¿Cómo funciona?
El programa revisa los archivos que hay en una carpeta y dependiendo del tipo (por ejemplo imágenes, documentos, videos, etc.), los mueve a diferentes carpetas.

Si las carpetas no existen, el programa las crea solo.

## Cómo usarlo
1. Descargar el proyecto
2. Abrirlo en Visual Studio Code
3. Ejecutar el archivo app.py
